Support

We answer every request by email.

Before writing

  • Check the troubleshooting section of the user guide: Orca Celebrations, Orca Service Monitor.
  • Make sure you run the latest version of the extension, and that your Magento and PHP versions are supported (Magento 2.4.7 or later, PHP 8.2 to 8.5).

Contact

Email orcashop.team@gmail.com and include:

  • the extension and its version (composer show orca/*);
  • your Magento edition and version, and your PHP version;
  • what you expected and what happened, with screenshots if possible;
  • related lines from var/log/exception.log and var/log/system.log.
Never send us admin passwords, API keys or database dumps by email. If we need access to a server, we will agree on a secure way first.

Scope

Support covers the extension itself on supported versions. We are happy to help with conflicts with other extensions or themes, but we can't guarantee a fix for code we don't maintain.
